API d'Intégration Partenaire

Guide officiel pour la connexion de Benda Bus au système de paiement Zola Money Trans.

Sécurité & Authentification

Toutes les requêtes vers l'API Zola Money Trans doivent inclure le header X-Zola-Api-Key contenant la clé secrète fournie par l'administrateur Zola.

1. Initier un Paiement

Ce point de terminaison permet à Benda Bus d'initier un paiement. En réponse, Zola fournira une URL de paiement (checkoutUrl) vers laquelle rediriger l'utilisateur final.

POST https://us-central1-zolamoneytrans.cloudfunctions.net/bendabusInitPayment

Corps de la requête (JSON)

{ "merchantReference": "RESERVATION:BND-2026-HBY9MH", "amount": "100.00", "currency": "USD", "paymentMethod": "MPESA", "callbackUrl": "https://api.bendabus.com/api/payments/callback" }

Réponse de succès (HTTP 200)

{ "success": true, "transactionId": "TX123456789", "checkoutUrl": "https://zolamoneytrans.com/pay.html?txId=TX123456789", "amount": 100.00, "currency": "USD", "fee": 9.50 }

2. Callback Benda Bus (Confirmation de Paiement)

Une fois le paiement complété avec succès ou échoué par le client sur la page Zola, notre système effectuera automatiquement un appel (POST) vers votre endpoint de callback.

POST https://api.bendabus.com/api/payments/callback

Headers envoyés par Zola

Content-Type: application/json X-Benda-Callback-Token: Xmaler895XtpLhfhf55Ka0086!jgkLL@hgytkg--

Format de la charge utile (JSON)

{ "eventId": "PAY-TX123456789-PAID", "merchantReference": "RESERVATION:BND-2026-HBY9MH", "providerReference": "TX123456789", "status": "PAID", "amount": 100.00, "currency": "USD", "paymentMethod": "MPESA", "sourcePlatform": "API_PARTENAIRE", "paidAt": "2026-07-22T21:45:00.000Z" }

Le statut (status) sera l'un des suivants : PAID, PENDING, FAILED, CANCELLED, ou EXPIRED.

3. Reversements (Payouts)

Conformément à l'accord de partenariat, Zola Money Trans prélève des frais de 9.5% sur les montants collectés. Le montant net (Montant initial - Frais de 9.5%) est ensuite reversé automatiquement ou manuellement sur le compte Mobile Money configuré par l'administrateur Zola.
