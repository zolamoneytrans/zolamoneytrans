Zola Money Trans API V1

Guide complet d'intégration pour les partenaires et les marchands.

1. Introduction

L'API Zola Money vous permet d'intégrer facilement les paiements Mobile Money (Airtel, M-Pesa, Orange, Africell, Cartes Bancaires) directement dans votre application web ou mobile.

Authentification : Toutes les requêtes vers l'API nécessitent une clé secrète (X-Zola-Api-Key) qui vous sera fournie par l'administrateur Zola Money.

Base URL : https://us-central1-zolamoneytrans.cloudfunctions.net

2. Initialiser un Paiement

Pour démarrer un paiement, vous devez appeler l'endpoint d'initialisation. Cet appel vous retournera une URL de paiement sécurisée (checkoutUrl) vers laquelle vous devrez rediriger votre client.

Endpoint

POST /zolaApiInitPayment

En-têtes (Headers)

Content-Type: application/json
X-Zola-Api-Key: zola_live_xxxxxxxxxxxxxxxxxxxxxxxxxxx

Corps de la requête (JSON)

{
  "merchantReference": "CMD-2026-8945",
  "amount": 50.00,
  "currency": "USD",
  "allowedMethod": "ALL" 
}

Le paramètre allowedMethod est optionnel. Valeurs possibles : "ALL" (Défaut, Mobile Money + Carte Bancaire), "MOBILE_MONEY" ou "BANK_CARD".

Réponse de Succès (200 OK)

{
  "success": true,
  "transactionId": "txn_8f9da2...",
  "checkoutUrl": "https://zolamoneytrans.com/pay.html?txId=txn_8f9da2...",
  "amount": 50,
  "currency": "USD",
  "fee": 4.75,
  "feePercentage": 9.5
}

Action requise : Redirigez l'utilisateur vers la checkoutUrl pour finaliser le paiement sur l'interface sécurisée Zola Money.

3. Webhooks (Callbacks)

Une fois que le client a finalisé le paiement, Zola Money enverra une notification asynchrone (Webhook) à votre serveur.

Fournissez votre URL de Webhook à l'administrateur Zola Money pour l'enregistrer dans votre configuration.

Requête Webhook envoyée par Zola Money

POST {Votre Webhook URL}

Headers:
Content-Type: application/json
X-Zola-Callback-Token: {Votre ID Partenaire}

Body (JSON):
{
  "eventId": "PAY-txn_8f9da2-PAID",
  "merchantReference": "CMD-2026-8945",
  "providerReference": "txn_8f9da2...",
  "status": "PAID",
  "amount": 50.00,
  "currency": "USD",
  "paymentMethod": "AIRTELMONEY",
  "sourcePlatform": "ZOLA_MONEY",
  "paidAt": "2026-07-23T10:00:00.000Z"
}

Statuts Possibles

StatutDescription
PAIDLe paiement a été effectué avec succès. Vous pouvez livrer la commande.
FAILEDLe paiement a échoué (Fonds insuffisants, erreur opérateur).
CANCELLEDLe client a annulé la transaction.

Sécurité : Vérifiez toujours que X-Zola-Callback-Token correspond bien à votre ID Partenaire (fourni par l'administrateur).

4. Reversements (Payouts)

Les reversements correspondent à l'argent que Zola Money vous transfère (Montant initial moins les frais de service).

  • Reversement Automatique : Si configuré, dès qu'un paiement est PAID, le montant net est immédiatement envoyé sur votre compte Mobile Money.
  • Reversement Manuel : Les reversements sont cumulés et approuvés manuellement par l'administrateur de Zola Money.

Discutez avec l'administrateur pour définir vos préférences (Numéro, Réseau et Mode).
